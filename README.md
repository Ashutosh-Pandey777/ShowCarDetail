# 🚗 ShowCarDetail

A modern car marketplace website built with React, Vite, Tailwind CSS and ASP.NET Core Web API.

---

## 🌐 Project Preview

![ShowCarDetail Website](./screenshot.png)

---

## ✨ Features

- 🏠 Modern Home Page
- 🚗 Browse Cars
- 🔍 Search and Filter Cars
- 📋 Car Details
- ⚖️ Compare Cars
- 💰 EMI Calculator
- 👤 User Registration & Login
- 🔐 JWT Authentication
- 🛠️ Admin Dashboard
- 🚘 Car Management
- 🏷️ Brand Management
- 📰 News Management
- ⭐ Review Management
- 📩 Contact Management
- 🖼️ Image Upload
- 📊 Visit Tracking

---

## 🛠️ Technologies

### Frontend

- React
- Vite
- Tailwind CSS
- JavaScript
- React Router
- Axios

### Backend

- ASP.NET Core 8 Web API
- Entity Framework Core
- JWT Authentication

### Database

- Microsoft SQL Server
